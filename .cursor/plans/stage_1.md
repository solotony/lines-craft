# Stage 1 — Research and Visual Specification

## Goal
Document interface geometry, 16-color palette, font approach, and permitted rasters from `docs/images/640x480` references.

## Tasks
- Measure board, panels, characters, and chrome from canonical 640×480 screenshots
- Define exactly 16 RGB colors
- Choose pixel-text font strategy
- Write `docs/visual-reference.md`

## Acceptance

- Geometry documented in virtual pixels
- Palette has exactly 16 unique colors
- Pixel-text enlargement method defined
- Permitted raster assets listed
