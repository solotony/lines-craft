In the original Color Lines by Gamos (DOS, 1992), points are awarded for removing balls by forming a continuous line of five or more balls of the same color. A line can be horizontal, vertical, or diagonal. The longer the line, the more points you score.

For the 1992 Gamos version, it is important not to confuse its scoring system with the rules used in later clones.

The complete scoring table for the original version could not be reliably verified from the available sources. For implementation purposes, the following table from a version of Lines 98 can serve as a reference, but it should not automatically be considered the exact scoring formula used in Gamos Color Lines 1992.

| Balls in a line | Points |
| --------------- | ------ |
| 5               | 10     |
| 6               | 12     |
| 7               | 18     |
| 8               | 28     |
| 9               | 42     |

For a faithful recreation of Gamos Color Lines 1992, I would not finalize this scoring table yet. It would be better to verify the original DOS version or its source code, if available, because different versions use different scoring formulas.
